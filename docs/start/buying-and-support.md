# Buying, roles, and support

## Buying

Scripts are sold on the GUM Scripts Tebex store: [gum-scripts.tebex.io/category/redm](https://gum-scripts.tebex.io/category/redm).

Do not open a ticket to ask for a discount code. Sales run regularly.

Scripts bought from third-party vendors are not supported.

## Discord roles

Support is given to script owners and their approved developers. Each purchase gets **one owner role** and **one developer role**.

- **Owner:** open a role request ticket in the Discord. You will be asked for a screenshot of the Tebex receipt from your email.
- **Developer:** the owner of the script opens a role request ticket and asks for the developer role to be given to you.

## Where to ask

| You need | Go to |
|---|---|
| Help with a script | The all-script-support forum in the Discord. Find the topic for your script and post in it. |
| To report a bug | The bug report channel in the Discord. Be clear and include details. |
| A Discord role, custom work, or a sales question | A ticket |
| To give a script to someone else | A ticket |

Tickets are only for roles, custom work, and sales. Script questions go in the support forum.

The Discord's text channels are English only.
